Ollama

AutoPlaylist sends your library's artist and track names to this server so the model can choose what belongs on a playlist. Nothing is sent anywhere else, and the plugin never reads your own playlists. If the URL points at a cloud-hosted model, those prompts leave your machine.
For example http://localhost:11434.
Any instruct model works. Bigger models curate noticeably better; the plugin asks for JSON and tolerates models that wrap it in prose.
